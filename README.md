# GEHL website

Static site for the Geotechnical Earthquake and GeoHazards Lab (KAIST), served by GitHub Pages at https://gehl-kaist.github.io.

`index.html` is self-contained; `site.json` is a readable copy of the content embedded in it. The files are produced from the editing copy on claude.ai and placed in the lab's Dropbox folder, which `sync-to-github.ps1` (a Windows scheduled task on each lab computer that shares the folder) mirrors into this repository when an update is requested.
